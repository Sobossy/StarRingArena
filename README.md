# 星环竞技场

Windows 本地 2D 自动对战游戏。选择两个角色及各自的移动策略，观看飞剑、火球、护盾反击和冲刺斩击交锋。

当前角色是标有“占位”的临时图形；正式美术由使用者提供。游戏支持透明 PNG，替换图片不会改变技能或碰撞规则。

## 开始玩

- **发行版：** 打开 `build/Windows/SpiritArena.exe`。请保持同目录的 `SpiritArena.pck` 与许可证文件完整；复制或分享时复制整个 Windows 文件夹。
- **从工程启动：** 双击 `StartGame.cmd`。缺少工具时脚本会自动下载 Godot 4.7.2。
- **开发编辑：** 双击 `OpenEditor.cmd` 打开 Godot 工程。
- **重新打包：** 双击 `BuildGame.cmd`。默认先运行回归测试，成功后导出 Windows x64 程序。
- **只运行测试：** 双击 `RunTests.cmd`，结果写入 `test-results/latest.log`。

首次完整配置会下载官方 Godot 编辑器及约 1.28 GB 的导出模板压缩包，只提取 Windows x64 模板。已经下载的文件会复用。工具位于工程的 `tools` 目录，无需另外安装 .NET、Unity 或 Visual Studio。发行版本身离线运行，无需游戏引擎或账号。

## 操作与规则

1. 选择青方与金方角色。
2. 为双方选择碰壁反弹、主动追击、保持距离或自由游走。
3. 点击“开始对战”。双方自动移动和放技能。
4. 可暂停、切换 0.5／1／2 倍速、调整音量、重开或返回选角。

| 快捷键 | 功能 |
| --- | --- |
| Space | 暂停／继续对战 |
| R | 使用当前配置重新开局 |
| F11 | 全屏／窗口切换 |

每局最多 90 秒。生命归零判负，同一模拟步内双方死亡为平局；超时比较剩余生命比例，比例相同为平局。双方可以选择同一个角色，状态和技能冷却独立。

对战种子决定随机移动。**同一版本、角色参数、策略和种子**可重复同一结果；换一组种子可以观察不同战况。倍速只改变观看速度，规则按固定 60 Hz 模拟。样例数值用于展示机制，并非已经完成竞技平衡。

音量、选角、策略与种子保存在 `%APPDATA%/StarRingArena/settings.cfg`。日志通常位于同目录的 `logs` 文件夹。

## 放入你的素材

详见 [素材接入说明](docs/素材接入.md)。推荐将透明 PNG 放在 `assets/characters/` 中，然后在角色 `.tres` 资源的 `portrait` 属性中指定图片。角色显示大小和偏移与碰撞半径分开调整。

背景可放在 `assets/arena/background.png`，游戏会自动使用它替换竞技场内部的程序背景。修改素材后重启工程；发行版需要重新打包。

## 增加角色与技能

详见 [角色与技能扩展](docs/角色与技能扩展.md)。可运行的第五角色例子位于 [风行者示例](examples/wind_pulse/README.md)，展示如何通过现有接口新增范围伤害、治疗与击退，不修改战斗核心。

```text
data/characters/       角色资源：图片、基础属性、策略、技能场景
data/roster.gd         选角登记表
scripts/core/          战斗规则与独立角色状态
scripts/movement/      四种可替换移动策略
scripts/skills/        技能脚本与基类
scenes/skills/         技能场景与可调参数
scripts/ui/            界面与表现层
examples/wind_pulse/   第五角色完整扩展示例
tests/                 自动化回归测试
tools/                 固定版本工具、下载缓存、许可文件
```

首版范围为离线 1 对 1。技能由工程代码扩展；不包含联网、多人混战、游戏内节点编辑器或运行时外部脚本加载。

## 工具与许可

Godot 引擎及导出模板固定为 **4.7.2 stable**，安装脚本校验官方 SHA-512。中文字体使用 Noto Sans SC。详见 [第三方说明](THIRD_PARTY_NOTICES.md)。临时头像、场地和通用特效由程序绘制，音效由程序合成；未提取参考视频中的角色图片或音频。
