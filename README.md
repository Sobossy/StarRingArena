# 星环竞技场

Windows 本地 2D 自动对战游戏，当前版本 **0.2.0**。支持角色编辑、多状态形象、矩形地图、2～8 人个人竞技和 2～4 队组队对战。

已经接入使用者提供的 416 张《崩坏：星穹铁道》表情 PNG。内置彦卿、姬子、杰帕德、刃四套示例形象，技能为自定义示例模板。编辑页支持搜索素材库或导入自己的 PNG，替换图片不会改变碰撞规则。

## 角色编辑与多人配置

点击主界面的 **角色编辑**，即可新增、复制角色，修改血量、攻击力、速度、常规图片、显示大小及碰撞半径。在“技能与状态”页为每个技能添加蓄力和释放图片，设置真实蓄力时长、释放图片时长，以及蓄力时能否移动。可预览图片并试放所选技能。

图片既可从文件导入，也可点击 **素材库** 按角色或表情名搜索。保存后在下次开局生效。退出编辑页或关闭窗口时，有未保存修改会提示处理。

主界面可以分别设置地图宽高（480～2400）、人数（2～8），并逐个选择角色、移动策略和队伍。组队允许 2～4 队且人数不同，队友无伤害。详见 [新版使用说明](docs/角色编辑与多人对战.md)。

## 开始玩

- **发行版：** 打开 `build/Windows/SpiritArena.exe`。请保持同目录的 `SpiritArena.pck` 与许可证文件完整；复制或分享时复制整个 Windows 文件夹。
- **从工程启动：** 双击 `StartGame.cmd`。缺少工具时脚本会自动下载 Godot 4.7.2。
- **开发编辑：** 双击 `OpenEditor.cmd` 打开 Godot 工程。
- **重新打包：** 双击 `BuildGame.cmd`。默认先运行回归测试，成功后导出 Windows x64 程序。
- **只运行测试：** 双击 `RunTests.cmd`，结果写入 `test-results/latest.log`。

开发者可运行 `Package.ps1` 在测试与构建后生成 Windows 与源码 ZIP。源码包包括素材、代码和工具脚本，排除引擎、下载缓存、`.godot` 和构建产物。

首次完整配置会下载官方 Godot 编辑器及约 1.28 GB 的导出模板压缩包，只提取 Windows x64 模板。已经下载的文件会复用。工具位于工程的 `tools` 目录，无需另外安装 .NET、Unity 或 Visual Studio。发行版本身离线运行，无需游戏引擎或账号。

## 操作与规则

1. 选择个人竞技或组队对战，设置人数和地图尺寸。
2. 为每个参战位置选择角色和移动方式；组队时分配 A～D 队。
3. 点击“开始对战”。双方自动移动和放技能。
4. 可暂停、切换 0.5／1／2 倍速、调整音量、重开或返回选角。

| 快捷键 | 功能 |
| --- | --- |
| Space | 暂停／继续对战 |
| R | 使用当前配置重新开局 |
| F11 | 全屏／窗口切换 |

每局最多 90 秒。最后一个存活角色或队伍获胜，同一模拟步全灭为平局。超时比较整队剩余生命总和÷开局生命上限总和（死亡成员也计入分母），比例并列为平局。个人竞技按个人比例比较。同一角色可以重复出场，状态、形象和技能冷却独立。

对战种子决定随机移动。**同一版本、角色参数、策略和种子**可重复同一结果；换一组种子可以观察不同战况。倍速只改变观看速度，规则按固定 60 Hz 模拟。样例数值用于展示机制，并非已经完成竞技平衡。

音量、阵容、策略、地图与种子保存在 `%APPDATA%/StarRingArena/settings.cfg`。角色配置和导入图片在同目录的 `characters/` 下。更新游戏时保留该数据目录；原 PNG 移动后仍可显示导入的副本。

## 四套示例角色

| 角色 | 默认移动 | 机制 |
| --- | --- | --- |
| 彦卿（飞剑） | 碰壁反弹 | 三柄环绕飞剑，按接触间隔造成伤害 |

## 放入你的素材

推荐直接在游戏的角色编辑页导入 PNG 或使用内置素材库，保存即可使用，无需重新打包。开发者也可按 [素材接入说明](docs/素材接入.md) 修改工程默认素材。

背景可放在 `assets/arena/background.png`，游戏会自动使用它替换竞技场内部的程序背景。修改素材后重启工程；发行版需要重新打包。

## 增加角色与技能

详见 [角色与技能扩展](docs/角色与技能扩展.md)。可运行的第五角色例子位于 [风行者示例](examples/wind_pulse/README.md)，展示如何通过现有接口新增范围伤害、治疗与击退，不修改战斗核心。

```text
data/characters/       角色资源：图片、基础属性、策略、技能场景
data/roster.gd         选角登记表
scripts/core/          战斗规则与独立角色状态
scripts/movement/      四种可替换移动策略
scripts/skills/        技能脚本与基类
scenes/skills/         技能场景与可调参数
scripts/ui/            界面与表现层
examples/wind_pulse/   第五角色完整扩展示例
tests/                 自动化回归测试
tools/                 固定版本工具、下载缓存、许可文件
```

当前为离线 2～8 人自动对战。新技能机制由工程代码扩展，角色编辑页组合已注册的技能模板；不包含联网、技能节点编辑器或运行时外部脚本加载。

## 工具与许可

Godot 引擎及导出模板固定为 **4.7.2 stable**，安装脚本校验官方 SHA-512。中文字体使用 Noto Sans SC。角色 PNG 来自使用者提供的素材目录；场地、占位图和通用特效由程序绘制，音效由程序合成。详见 [第三方说明](THIRD_PARTY_NOTICES.md)。

## 开发基线

原双人版有 Git 标签 `baseline-v0.1.0`，源码与运行包另保存在工程 `build/baselines/`，可用于恢复或比较。当前扩展通过原有规则测试、新增多人及存档测试和界面集成测试后再打包。
