# 云璃（0.7.0）

默认1000血、160速度、碰壁反弹，无普通身体碰撞伤害。

## 吃串与防反

- 常态使用`225_云璃 好吃.png`吃琼实鸟串，每满1秒回复30生命，上限为最大生命；绿色飘字显示实际回复量。
- 首次有效攻击先正常结算，然后切换`223_云璃 威慑.png`进入4秒防反。触发这一击不计入防反累计，也不享受新获得的减伤。
- 防反期间继续移动，后续伤害减少20%；再次受击不叠加减伤、不刷新4秒。常态回血暂停，回到常态后重新按1秒计时。
- 防反累计取减伤和护盾结算后实际扣除的生命，不计护盾吸收量。不会因为攻击被标记为禁止反击链而漏记实际伤害。
- 4秒结束时锁定最近存活敌人当前方向，投出独立旋转飞行的“老铁”，伤害快照为`150 + 防反期间实际扣血 × 0.4`，同时恢复吃串图。

例如：第一击100伤害触发防反；随后100伤害实际扣80，再受到50伤害实际扣40，则累计120，老铁伤害为`150 + 120×0.4 = 198`。

老铁在释放瞬间朝最近存活敌人当时所在位置的方向直线投出，出手后不追踪、不折返，也不在目标位置停止。命中后继续向前飞，沿途每名敌人仅受伤一次，穿过队友不造成伤害；完全飞出地图后清理。飞行时间随地图大小和速度自动适配，取消原先的4秒飞行上限，旧存档中的该参数不再生效。保留击退、逆时针旋转受击和命中特效。云璃出手后可继续回血，也可再次受击进入新一轮防反。死亡或战斗结束会取消尚未释放的防反，不会复活或延迟补放攻击。

## 在角色编辑页调整

在“角色编辑 → 云璃 → 属性与技能 → 技能与状态 → 技能数值”中调整：

| 参数 | 默认 |
| --- | --- |
| 常态每秒回复 | 30 |
| 防反持续时间 | 4秒 |
| 减伤比例 | 0.2（20%） |
| 老铁基础伤害 | 150 |
| 受伤转伤害倍率 | 0.4 |
| 老铁飞行速度 | 850 |
| 判定半径 | 24 |
| 击退强度 | 1000 |
| 旋转速度 | 10弧度/秒 |

常规图片对应吃串，技能的“蓄力形象”对应防反图片；防反时长使用专用数值，不使用通用蓄力/释放图片时长。试放技能会模拟一次受击，并完整播放4秒防反和老铁投掷。保存从下一局生效，各实例计时和受伤累计互不共享。
