# 声音与受击表现（0.4.0）

## 地图与画面

地图默认宽高为 **500×500**，指可活动区域，不含外框。仍可分别调整为480～2400。第一次升级时，原默认664×664自动改为500×500，其他自定义尺寸保留；迁移标记写入设置，之后用户主动设回664×664也不会再次被覆盖。

战场和编辑预览不再显示角色常驻装饰圆环与头顶名称/编号，保留血条、生命数、飘字、护盾、蓄力和状态提示。角色名称继续出现在选角、侧栏、编辑及结算中。

## 声音控制

主界面“总音量”控制音乐、命中音效和淘汰欢呼。“背景音乐”开关与旁边滑条仅控制音乐，初次默认开启、50%，总音量沿用35%的默认设置。音乐来自用户提供的HOYO-MiX曲目，从选角起循环播放。

关闭音乐只静音，保留播放进度；滑条为0时开关仍可保持开启。开关及音量随其他设置保存在`%APPDATA%/StarRingArena/settings.cfg`，重启恢复。编辑、重开、结算和暂停不会重新起播音乐，倍速不会改变音乐速度。返回选角或重开会停止旧的淘汰欢呼，背景音乐继续。

## 重击

带击退的有效攻击会同时造成伤害和受击反馈，护盾吸收也有效；友军或无效攻击不产生击退。碰撞重击、近战及冲刺使目标远离攻击者，球棒沿命中那一刻的实际飞行方向击退，返程也适用。普通身体分离、碰墙、持续灼烧不会新增重击伤害。

击退期间冲量主导移动，自主移动和冲刺位移暂时被压制，其原有计时继续。初速度按`exp(-8×时间)`衰减，低于60或满0.6秒时结束。角色图片以每秒720°持续逆时针旋转，叠加上浮、闪白和放射线；之后用0.12秒沿逆时针回正。血条与碰撞范围不旋转。连续受击重新定向和计时，旋转角度连续。

碰撞重击初始冲量1100、球棒900；其他已有击退技能保留原强度。暂停冻结整个受击过程，倍速按战斗时间生效。贴墙清除朝墙的冲量，避免穿墙和卡死。

技能作者使用兼容的新接口：

```gdscript
# 第五参数仍为是否允许受伤反应；第六参数是可选击退向量。
arena.apply_damage(fighter, target, damage, skill_id, true, direction * strength)
```

将击退与伤害同时提交，避免先直接修改`target.knockback`而绕过命中验证。无击退时仍可沿用原调用。

## 击杀退场

死亡角色立即失去攻击、移动和被选为目标的资格，立即计入淘汰与胜负判断；动画独立于战斗结算。图片在死亡位置停顿0.5秒，随后沿最后受击方向旋转飞出场外，飞行0.45秒；无受击方向时沿地图中心向外，位于中心则朝上。

飞出开始时播放欢呼，短时间内多人同时淘汰合并欢呼，避免音量叠加。最后一批退场完成后显示胜负界面；全灭仍为平局，存活者超时结算不播放死亡动画。暂停和倍速影响退场时间，音乐和欢呼音高不受倍速影响。重开及返回清空旧动画。

自动检查为`tests/feedback_tests.gd`，实际窗口绘图和音频播放检查为`tests/feedback_visual.gd`。源码和独立程序均随包携带两个OGG，不需要访问原素材目录或网络。
