# 声音与受击表现（0.4.0）

## 地图与画面

地图默认宽高为 **500×500**，指可活动区域，不含外框。仍可分别调整为480～2400。第一次升级时，原默认664×664自动改为500×500，其他自定义尺寸保留；迁移标记写入设置，之后用户主动设回664×664也不会再次被覆盖。

战场和编辑预览不再显示角色常驻装饰圆环与头顶名称/编号，保留血条、生命数、飘字、护盾、蓄力和状态提示。角色名称继续出现在选角、侧栏、编辑及结算中。

## 声音控制

主界面“总音量”控制音乐、命中音效和淘汰欢呼。“背景音乐”开关与旁边滑条仅控制音乐，初次默认开启、50%，总音量沿用35%的默认设置。音乐来自用户提供的HOYO-MiX曲目，从选角起循环播放。

关闭音乐只静音，保留播放进度；滑条为0时开关仍可保持开启。开关及音量随其他设置保存在`%APPDATA%/StarRingArena/settings.cfg`，重启恢复。编辑、重开、结算和暂停不会重新起播音乐，倍速不会改变音乐速度。返回选角或重开会停止旧的淘汰欢呼，背景音乐继续。

## 角色语音与吃串音效

- 迷迷连续拳击时循环播放用户提供的“欧拉欧拉”，每名角色只持有一条拳击音轨，不按每秒13拳反复启动或叠加。普通停止攻击后延续0.2秒战斗时间，最后0.12秒平滑淡出；收尾期间重新出拳会继续同一段音轨并恢复音量，避免断句和重播。记忆·星腾空、死亡、胜负确定、重开和返回时立即停止。暂停及其他角色的时停冻结收尾进度，倍速按战斗时间生效。
- 记忆·星实际开启时停时播放一次“时停”，不会因时停状态每帧更新而重复播放。
- 两段记忆语音按原文件的低响度补偿为+6分贝，拳击的第一拳即启动语音，后续连打不重播。语音播放时背景音乐平滑降低8分贝、命中声降低8分贝，结束后自动恢复；不改变保存的音乐开关和音量值。多名记忆·星同时出拳时对同类语音进行幅度补偿，避免叠加过响。
- 云璃处于常态吃琼实鸟串时循环播放“MC吃东西”，包括满血时；进入防反立即停止，投出老铁后恢复常态时重新播放。
- 新音效统一受“总音量”控制，不受“背景音乐”开关影响；0.5／1／2倍速同步改变其播放速度及音高，背景音乐保持原速。战斗暂停和其他角色的时停会暂停对应音轨，恢复后接着播放；手机切后台时暂停。
- 角色死亡、胜负确定、重开或返回选角时清理旧音轨。多人使用同一角色时各自独立播放，并按同类同时播放数量降低单条音轨音量。编辑页试放复用相同逻辑，停止预览或关闭编辑页会清理预览声音。

## 冲刺虚化与受击压缩

阿格莱雅仅在沿金线冲刺期间，角色贴图带约1.2屏幕像素的轻微柔化，并沿实际经过的位置保留最多两个淡残影，透明度约10%和5%。转弯时使用真实路径上的旧姿态，不向墙外推算；冲刺结束、死亡或重开立即清除。金线、文字、血条和其他角色不参与模糊。

所有角色每次受到有效伤害（含护盾吸收）时，图片在0.04秒压至原高度84%，到0.12秒轻微回弹至102%，在0.18秒恢复。以图片中心为支点，宽度不随受击改变；保留原有呼吸浮动和闪白，受击压缩替代原先受击时的整体放大。连续命中从当前高度衔接，不乘算叠加。灼烧、摔落也触发；治疗、零伤害、普通反弹不触发。致死一击在原地停顿阶段仍播放，飞出场外时恢复正常比例。

纵向压缩可与冲刺虚化、镜像、倾斜、逆时针旋转及腾空上浮叠加，真实碰撞范围、血条、文字、武器和投射物不被压缩。占位形象同样支持。暂停冻结效果，倍速按战斗时间推进；编辑页试放复用同一套表现，动画不改变伤害、移动或胜负。

## 普通碰撞反弹

所有地面角色互相碰撞时，即使没有碰撞伤害，也会像碰墙一样沿接触面反射移动方向。已有击退冲量也会反弹，保持原有强度衰减，不额外扣血或触发重击旋转。追击、保持距离、游走及主动找吐司等方向控制会让出0.2秒，避免刚反弹就立即转回而贴在一起；碰壁反弹策略会持续沿反射方向移动。腾空无碰撞及技能接管移动时仍按各自的特殊规则处理。

## 重击

带击退的有效攻击会同时造成伤害和受击反馈，护盾吸收也有效；友军或无效攻击不产生击退。碰撞重击、近战及冲刺使目标远离攻击者，球棒沿命中那一刻的实际飞行方向击退，返程也适用。普通身体分离、碰墙、持续灼烧不会新增重击伤害。

击退期间冲量主导移动，自主移动和冲刺位移暂时被压制，其原有计时继续。初速度按`exp(-8×时间)`衰减，低于60时结束，不再受原先0.6秒上限限制。角色图片以每秒720°持续逆时针旋转，叠加上浮、闪白和放射线；之后用0.12秒沿逆时针回正。血条与碰撞范围不旋转。连续受击重新定向和计时，旋转角度连续。

毁灭·星碰撞重击当前默认冲量2400、球棒1000；其他已有击退技能保留各自强度。暂停冻结整个受击过程，倍速按战斗时间生效。击退碰到墙壁会反转对应方向，墙角会分别反转两个方向，继续弹飞和逆时针旋转直到冲量衰减结束。反弹不会额外消耗或重置击退强度，不会新增碰墙伤害；角色保持在地图范围内。

技能作者使用兼容的新接口：

```gdscript
# 第五参数仍为是否允许受伤反应；第六参数是可选击退向量。
arena.apply_damage(fighter, target, damage, skill_id, true, direction * strength)
```

将击退与伤害同时提交，避免先直接修改`target.knockback`而绕过命中验证。无击退时仍可沿用原调用。

## 击杀退场

死亡角色立即失去攻击、移动和被选为目标的资格，立即计入淘汰与胜负判断；动画独立于战斗结算。图片在死亡位置停顿0.5秒，随后沿最后受击方向旋转飞出场外，飞行0.45秒；无受击方向时沿地图中心向外，位于中心则朝上。

飞出开始时播放欢呼，短时间内多人同时淘汰合并欢呼，避免音量叠加。全灭仍为平局，存活者超时结算不播放死亡动画。暂停和倍速影响普通退场时间，音乐和欢呼音高不受倍速影响。重开及返回清空旧动画。

胜负确定后立即锁定血量、伤害统计和结果，停止攻击、状态伤害及缩圈；所有幸存者沿当前方向，以常态移速继续移动和碰壁/身体反弹。动作跟随倍速，但结算等待固定为现实时间4秒：0.5倍、1倍、2倍都等待4秒。手动暂停、手机切后台冻结等待，回到前台需手动继续。超时和平局也使用相同等待。4秒到时幸存者停止并弹出结果，不因退场动画尚未结束延长；重开与返回清除计时。

黄泉迷路是独立的立即判负退场：使用迷茫形象，沿碰墙前的完整实际速度向量匀速离场，包括当时的击退速度；不额外加速、停顿或旋转。离场动画同样跟随暂停和倍速，完全离开可视区域后清理。

## 绯英冲撞鸣笛
吃到吐司后，在蓄力最后一个完整鸣笛时长播放 feiying_horn.mp3（约1.13秒），末尾对齐大运冲撞。蓄力短于音频时延长至完整音频时长。暂停、时停、腾空等待冻结鸣笛及蓄力；倍速同步播放速度，取消、死亡、结束或重开停止声音。


## 通用受击声与毁灭·星撞墙追加伤害
所有角色每次结算有效伤害（包括护盾吸收、持续伤害和致死伤害）播放用户提供的受击声，正式对战与技能试放共用。零伤害和普通无伤碰撞不播放。
毁灭·星碰撞重击的击退首次撞墙追加20伤害，可在技能参数调整；外墙和黄泉切面墙均有效，墙角仅追加一次。后续普通反弹不重复追加，其他击退覆盖或击退结束清除资格。追加伤害计入毁灭·星统计，不再次施加击退。
