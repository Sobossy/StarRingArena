# 安卓使用说明

下载安装发布页的 `StarRingArena.apk`，应用名“星环竞技场”，包名 `com.starringarena.game`。安卓竖屏，与电脑共用角色、技能和战斗规则。

## 开发与安装

- `BuildAndroid.ps1`：配置便携工具并导出APK，不连接手机也可使用。
- `UpdatePhone.cmd`：重新导出并覆盖安装到已连接、授权USB调试的手机，保留角色、设置和记录。
- `InstallAndroid.ps1 -Device 设备序号`：将现有APK安装到指定手机；可加 `-Logs` 查看日志。
- `PreviewMobile.cmd`：在电脑查看竖屏布局。

首次通过USB安装时，若手机出现授权提示，请在手机确认。工具位于工程 `tools/` 目录，无需安装完整Android Studio。

## 操作与数据

手机采用“配置 / 对战”分页；角色编辑、素材选择和对局记录支持触屏操作。切后台自动暂停战斗与声音，返回前台后手动继续。

覆盖安装可保留数据，卸载会清除应用私有存储。电脑与手机的数据暂不自动同步。更新时使用相同包名和签名，不要先卸载旧版。

本地签名保存在 `tools/android/development.keystore`，不纳入Git或源码包。更换开发电脑时请保留原签名，否则无法覆盖此前安装的APK；脚本不会自动卸载旧应用。
