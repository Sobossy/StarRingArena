# 安卓边开发边测试（0.5.0）

手机测试版为 `build/Android/StarRingArena.apk`，应用名“星环竞技场”，包名固定为`com.starringarena.game`。基于当前Windows工程导出，共用角色、技能和战斗规则；后续功能同时验证电脑与手机。

## 快速循环

1. 手机开启USB调试，用数据线连接电脑，解锁并允许电脑调试。首次通过USB安装时，若手机询问是否允许安装，请在手机确认。
2. 双击`UpdatePhone.cmd`，重新导出测试APK并覆盖安装、启动，保留手机角色和设置。它用于快速迭代，会检查脚本、导出结果和签名，不运行耗时的全部规则检查。
3. 正式回归时双击`BuildAndroid.cmd`，完成全部规则测试再打包、安装。也可运行`BuildAndroid.ps1`只打包，不自动安装。
4. 没有连接手机时，用`PreviewMobile.cmd`在电脑预览竖屏触屏布局；有APK也可复制到手机手动安装。

日常开发采用快速迭代：只检查启动、核心流程和本次改动，优先交付手机可试玩版本；完整回归放在阶段交付时执行。

连接多台设备时使用`TestOnPhone.ps1 -Device 设备序号`指定一台。该脚本仅覆盖安装此游戏，不卸载旧版、不清除角色和设置。`TestOnPhone.ps1 -Logs`安装启动后显示游戏日志。

## 手机界面

采用竖屏游玩，手机端以720×1280为逻辑基准并适配更长的屏幕。默认打开“配置”页，设置500×500地图、2～8人、角色和队伍；点“开始对战”进入完整战场页，正方形战场按可用宽度显示。下方大按钮提供暂停、返回配置、0.5/1/2倍速、重开；右上角“配置/声音”可调整音量，切到配置时自动暂停，回到战场手动继续。

角色编辑按“角色库 / 属性与技能 / 形象预览”分页，属性与技能页继续分基础属性、常规形象及技能状态。可滚动并用数字键盘修改数值。PNG导入调用安卓系统文件选择器，只需授权选择的文件，不申请整个存储空间权限；选中后复制进游戏私有存储。内置416张素材也可直接使用。

系统返回键优先关闭素材弹窗或返回编辑页；离开有修改的编辑页仍提示保存。战场返回键进入配置并暂停，配置页再返回会询问退出。切后台保存设置并暂停战斗/声音；返回前台恢复声音，战斗保持暂停，由你继续。

## 更新与数据

电脑和手机各自保存角色与设置，目前不会自动同步。手机数据在安卓应用私有目录，覆盖更新保留，卸载会清除。不要卸载旧版来更新；使用相同包名和签名覆盖安装。

本地开发签名位于`tools/android/development.keystore`，首次配置生成，后续重复使用。请随工程本地备份保留此文件；源码压缩包不包含签名和下载的工具。更换电脑时若要覆盖已有手机安装，需要迁移这个签名文件。没有原签名时脚本会报告安装失败，不会自动卸载或删数据。

手机默认目标60 FPS，以减少耗电；开发测试版每5秒在游戏日志输出一次`PHONE_PERF`采样，便于后续功能迭代时检查。它不显示在游戏界面中。

工具安装为工程目录内的便携Temurin JDK17、Android命令行工具/SDK36、Godot4.7.2对应导出模板，不需要完整Android Studio或重新制作角色素材。本次APK是开发测试版，后续应用商店发布另设正式签名及发布流程。
