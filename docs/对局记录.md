# 对局记录与自动随机种子

双击工程根目录 `StartGame.cmd` 运行最新源码。桌面顶部有“对局记录”，手机配置页提供同名入口；结算页可直接“查看本局记录”。本次仅更新本地工程，已有Windows运行包、APK与GitHub发行版不会自动更新。

## 哪些对局会保存

淘汰或超时正常结束的对局都会保存，包括平局。胜负一确定就保存，不等待结算前的现实4秒；此时立即重开或退出，已经完成的上一局仍有记录。对战中主动重开、返回选角、退出或崩溃，不会保存未结束的这一局。编辑页的技能试放不记入历史。

记录全部保留，不自动删旧对局。可以在列表删除单局，或确认后清空本机全部记录。胜负未定及结算前的4秒内禁用历史入口，查看历史不会改变已有的选角或结算状态。手机返回键依次返回“详情→列表→原画面”。

## 查看内容

- 列表按完成时间倒序，每页20局，显示阵容、模式、胜方/平局、时长和实际种子。
- “配置与统计”展示开局地图、人数、队伍、移动策略、角色属性、技能数值和最终生命、淘汰情况、伤害/治疗统计。造成与承受伤害均包含护盾吸收。
- 开局会固化技能当时的实际默认值、显式设置及名称；以后编辑角色或更新默认数值，不会改变旧战报。历史形象缺失时显示占位图，文字和数值仍可查看。
- “战斗事件”保存完整事件，不受4096条调试日志上限影响。每页100条，可按角色和事件类型筛选。包含伤害结算、治疗、护盾、状态、技能阶段、投射物、时停、吐司、缩圈、切面、击飞/落地和淘汰等事件。
- 每条事件有时间、序号、模拟步和相关参与者。记录不包含逐帧轨迹、装饰粒子或胜负已定后的4秒移动，不提供动态回放。

## 自动换种子

所有正式开局入口，包括开始、重新开局、快捷键R、手机重开和结算页“再战一局”，都会自动生成1～999999的新种子，并保证与上一局实际使用的种子不同。普通界面不再手动输入种子或显示“换一组”。

种子由独立随机源生成，不消耗战斗本身的随机序列。实际使用的种子显示在界面和战报中，上一局种子会保存；无效配置不会替换正在运行的对局。底层仍可用 `MatchConfig.seed_value` 进行固定种子测试；相同版本、角色配置、策略和种子下的战斗可重复。

## 本地保存与异常处理

Windows记录位于 `%APPDATA%/StarRingArena/match_history/`，安卓位于应用自己的数据目录，对应 `user://match_history/`。两端独立，不自动同步。备份时复制整个记录目录，角色与导入图片仍保留在同设备的 `characters/` 目录。

每局是一份独立JSON，`index.json`是列表的轻量索引。战斗中仅在内存收集，正常结束后先写完整临时文件，再原子替换；未完成的临时文件不会显示为完整记录。索引损坏或丢失时，会从完整记录自动恢复。

写入失败不会改变胜负，会提示“记录保存未完成”；在记录页点击“重试保存”可重试当前进程保留的完整记录。请在关闭游戏前重试成功，尚未落盘的数据无法跨进程保留。确认删除/清空只影响本地记录，不修改角色或对战设置。
