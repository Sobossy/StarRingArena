# 本地默认配置（0.7.1）

本次以电脑上已保存的角色配置为准，固化毁灭·星、花火、云璃三名当前角色的基础属性、形象、说明、技能阶段及全部技能数值。未保存覆盖配置的云璃沿用原内置值；已退役的四个角色不会重新加入。

毁灭·星的碰撞击退由本地保存的3400按此次明确要求调整为2400，同时更新电脑上的该角色覆盖配置。其余本地修改均保留。

| 技能 | 当前内置默认值 |
| --- | --- |
| 毁灭·星 · 碰撞重击 | 伤害80，击退2400，同目标间隔0.1秒，额外触发距离24 |
| 毁灭·星 · 蓄力回旋球棒 | 蓄力6秒，固定距离500，去/回程各80伤害，攻击半径30，击退1000，去程速度700、回程900 |
| 花火 · 六膛惊喜左轮 | 实弹180伤害，上膛0.1秒，扣扳机间隔1.6秒，子弹速度1400 |
| 云璃 · 吃串防反与老铁 | 常态每秒回血30，防反4秒、减伤20%，老铁伤害150＋防反实际受伤×0.4 |

基础属性页已移除基础攻击力输入，伤害在各技能自己的数值里设置。角色说明改为可换行、自动折行的文本域，保存并重开后保留换行。

新安装以及“恢复默认”使用以上内置配置；已有设备上的个人覆盖配置仍优先，需使用新默认值时可在角色编辑页选择该角色并点击“恢复默认”。电脑和手机的存档仍各自独立。本次固化为一次性的工程更新，之后在游戏中编辑仍只改变当前设备的个人配置。

本次修改前的源码和电脑角色存档备份保存在 `build/baselines/before-local-defaults-20261026/`，不进入运行包。后续只有收到明确指令才进行 Git 提交、推送或发布 GitHub 版本。
