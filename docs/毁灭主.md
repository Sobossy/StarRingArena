# 毁灭主（0.4.0）

选角列表或角色编辑页选择“毁灭主”。原始两张 PNG 保持不变，球棒和拖尾由游戏单独绘制。

## 两个技能

**蓄力回旋球棒**

- 常规、持棒与蓄力状态使用 `063_开拓者 球棒.png`。
- 未接触敌方身体且球棒在手时累积蓄力，默认 6 秒。选择敌人、瞄准位置均在实际出手时确定，不会提前锁定六秒前的位置。
- 球棒旋转并带拖尾，飞到该固定位置后，转为追踪本人手部并自动接回。敌人移动不会改变出程落点。
- 球棒离手的整个出程与回程均使用 `064_开拓者 棒球.png`；接回后才恢复持棒图并重新开始下一次蓄力，不会同时甩出第二根球棒。
- 同一趟往返对同一敌人最多造成一次投掷伤害；出程未命中的敌人仍可能在回程被命中。可以命中途经的多个敌人，不伤队友。

**碰撞重击**

- 接触敌方身体时造成更高伤害、强击退，并在击退全程逆时针旋转，叠加短暂上浮与闪白反馈。
- 立即重置自己的球棒蓄力；即使碰撞恰好发生在蓄满的同一个时间步，也先打断，不会出手。
- 持续贴身不逐帧重复攻击；分离后可再次触发，同一目标最短重击间隔为 0.65 秒。
- 球棒已经飞出时，身体碰撞仍可重击，但不会提前收回球棒或提前恢复持棒图片。
- 队友接触不触发重击，也不会打断蓄力。

## 编辑与默认数值

在“角色编辑 → 毁灭主 → 技能与状态”选择“蓄力回旋球棒”，修改蓄力时长，范围 0～60 秒，也可切换蓄力时允许移动。保存后下一局生效。

“释放形象持续时间”对这个技能不使用固定值，编辑页会禁用该项；离手形象由真实飞行与接回时机控制。两张图片仍可独立替换。

基础数值：血量 1100、攻击 40、速度 158、碰撞半径 28。

| 技能数值 | 默认 |
| --- | --- |
| 投掷伤害 | 基础攻击 × 1.5（默认 60） |
| 碰撞伤害 | 基础攻击 × 3（默认 120） |
| 出程速度 | 700 游戏单位/秒 |
| 回程速度 | 至少 900，并随角色速度提高以保证追上本人 |
| 碰撞击退 | 1100 游戏单位/秒的初始冲量，随后衰减 |
| 球棒击退 | 900 游戏单位/秒，沿命中时球棒的实际飞行方向（含返程） |

伤害倍率、飞行速度和击退量在对应技能场景/脚本中导出，可继续调试平衡。暂停、倍速、死亡、结束和重开均使用现有战斗时钟与清理规则。

## 验证

`tests/destruction_tests.gd` 检查蓄力时间、瞬间瞄准、往返与移动接回、图片生命周期、碰撞打断、贴身防重复、友方过滤、暂停、死亡和重开。

`tests/destruction_visual.gd` 在真实窗口绘制并输出蓄力、出程、回程、接回和击飞五种画面的截图。视觉参考为用户提供的 `QQ20261025-190722.mp4`，没有提取视频音轨或角色贴图。
