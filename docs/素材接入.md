# 素材接入

## 角色透明 PNG

推荐提供正方形画布、带透明通道的 PNG，每个角色单独一张。512×512 或 1024×1024 均可；并非强制尺寸。主体尽量居中，四周保留少量空白，不要把血条、伤害数字或文字画进角色图里。

1. 将素材放入 `assets/characters/`，例如 `my_sword.png`。
2. 双击 `OpenEditor.cmd`。
3. 在 Godot 文件列表打开 `data/characters/sword.tres`。
4. 将 PNG 拖到右侧 Inspector 的 **Portrait** 属性。
5. 保存资源并运行。

| 属性 | 用途 |
| --- | --- |
| `portrait` | 角色 PNG 纹理；为空时显示带“占位”标签的临时图形 |
| `portrait_size` | 最长边在 760×760 逻辑战场内的显示长度，默认 82 |
| `portrait_offset` | 图片的水平、垂直偏移，用于调整主体中心 |
| `radius` | 角色圆形碰撞半径，默认 28，与 PNG 透明边缘无关 |
| `theme_color` | 飞剑、拖尾、光圈和技能表现的主题色 |

游戏按图片宽高比缩放，负责浮动、移动倾斜、受击缩放及闪亮表现。血条、名称、状态和伤害数字由游戏独立绘制。

若主体在很大的透明画布中显得偏小，可增加 `portrait_size` 或预先裁剪画布。显示大小不自动修改碰撞半径，避免只换美术就改变玩法。

## 背景

将竞技场内部背景放在 `assets/arena/background.png`。推荐正方形、不带外框。游戏保留边框，背景被绘制到场地内部；未提供背景时使用程序网格与中央图案。

## 打包更新

工程素材改好后，双击 `BuildGame.cmd` 重新生成 `build/Windows`。发行版不会自动读取工程外的 PNG；需要将图片指定为角色资源并重新打包。

四个样例角色的资源文件分别为 `sword.tres`、`mage.tres`、`guard.tres`、`assassin.tres`。可以修改名字和图片，继续复用现有技能。
