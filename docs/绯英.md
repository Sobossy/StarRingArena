# 绯英 · 吐司与大运

默认1000生命、160移速、碰壁反弹，无普通身体碰撞伤害。常态为`039_绯英 好累.png`；拾取吐司后，蓄力与冲撞都使用`042_绯英 摄取知识.png`。

全场最多存在一片吐司，多名绯英也共享这一片。开局先随机生成一片，拾取后不再周期刷新；绯英冲刺撞墙结束后，默认等待1秒再随机生成下一片。吐司不再过期，位置由本局随机种子决定，在地图内尽量避开角色。任意一名未变身且在地面的绯英都可拾取，同一片只会被吃一次；其他角色无法拾取。多个刷新请求合并为一个倒计时，不叠加面包或推迟已有刷新。全部绯英死亡、结算或重开会清理吐司及待刷新状态；仍有其他绯英存活时可继续循环。

拾取立即回复125生命，上限为最大生命，并化身大运。默认原地蓄力1.5秒，在释放瞬间确定最近存活敌人的方向，随后直线冲撞。出手后方向固定，不追踪目标，也不在敌人位置停下。沿途命中敌人造成150伤害并击飞，每名敌人每次冲刺最多命中一次；命中后继续直冲到墙壁才停下，解除大运状态并开始1秒刷新倒计时。移除原来的最大距离限制，大地图也会冲到真正的边界。冲刺时继续承受伤害，但不会被普通击退打断；死亡会终止冲刺。

绯英未处于大运状态累计满5秒后，会主动向最近的吐司移动；没有吐司时继续原本移动方式。拾取和解除大运后重新计时。

被撞飞的目标进入独立腾空状态，默认持续1.5秒：

- 不与角色、投射物、近战、金线和冲刺判定碰撞，也不触发普通身体接触技能；仍可被选为瞄准目标。
- 自主移动、冲刺位移和额外击退暂停，技能计时与正常攻击继续，因此可在空中开枪、放球棒等。
- 水平落点在撞飞瞬间根据击飞方向和强度确定，并约束在地图内；飞行中不做墙壁或角色碰撞处理。图片上浮并持续逆时针旋转，血条保持稳定。
- 落地时恢复碰撞与移动，单独结算75摔落伤害；攻击者死亡也不会取消已经安排的落地伤害。仍遵循既有护盾和减伤结算，落地不引发即时反击链。
- 阿格莱雅正处于不可阻挡冲刺时，仍承受冲撞伤害，但不会被击退或强制腾空。

在角色编辑页选中“绯英 · 吐司与大运”，蓄力时长默认为1.5秒；下方技能数值可调整冲刺结束后的吐司刷新延迟（默认1秒）、吐司拾取半径、回血量、主动找吐司延迟、冲撞速度、伤害、判定半径、击飞强度、腾空时间及高度、落地伤害。旧的周期刷新、数量上限、吐司寿命和最大冲刺距离参数不再使用；全场最多一片和冲到墙壁为固定规则。技能形象可分别更换，释放形象的持续时间由实际冲撞过程决定。点击“试放所选技能”可完整查看拾取、蓄力、冲撞和落地。
