# 缇宝 · 百界门与彩虹火箭

常态使用 `131_缇宝 睿智.png`，默认1000生命、160移速、碰壁反弹。百界门的缇安、缇宁使用现有 `133_缇安 晚安.png` 与 `134_缇宁 发送.png`，不占参战人数。

## 百界门

存在存活的百界门技能角色时，全场共用两面门墙。开局立即从左、右、上、下四面外墙中随机选两面，六种组合等概率；默认每8秒重新随机，允许重复抽到当前组合。

两扇门互相连接：进入A门从B门出来，进入B门从A门出来。地面角色与火箭按沿门位置的归一化比例映射出口，兼容长方形地图和缩圈。相对墙的门不改变方向；相邻墙的门随出口转向90°，保持相对门的入射角及速度大小，击退冲量、反弹和普通移动方向同步旋转。传送后仍能正常与其他角色碰撞。出生、缩圈校正与身体分离不触发传送；腾空沿用原有无碰撞规则。

同刻撞到两扇门共用墙角时，以入射法向速度分量较大的门作为入口，相同时按固定墙面顺序选择，只计一次传送。出口沿墙位置避开墙角一个碰撞半径，避免零距离回传。

穿门不算碰墙，不增加金线锚点，不触发黄泉迷路或毁灭·星的撞墙追加伤害。绯英的大运随出口旋转方向并重新计算后续路径，可以连续穿门直到碰到实体墙；同一次大运仍只对同一目标命中一次。阿格莱雅沿金线冲刺期间忽略传送门，按原路线完成；常态穿门保留原锚点，活动金线连接出口，目标瞬移不产生横跨全场的扫掠伤害。

传送可以跨过黄泉切出的板块，出口重新确定角色所属板块。地图缩圈时门和出口随当前边界调整；门光、开门伙伴跟随棋盘外框及板块显示偏移。

## 火箭

任何角色或缇宝火箭每传送一次，都会让每个存活的百界门技能角色各发射一枚火箭。火箭从施术者位置出发，初始朝向最近敌人当时的位置，此后持续向随机一侧转弯，不追踪目标。转向保持速度大小，穿门时按出口旋转当前朝向，保留转弯速率、左右弯曲方向和寿命。

火箭碰到敌人、未开门的外墙，或飞行满10秒时爆炸。爆炸范围内的敌人各受到一次60伤害，直接碰撞不另加一份伤害，友军不受伤；护盾和受击反馈沿用统一伤害结算。火箭穿过黄泉切面。墙角同时有实体墙与门时，火箭优先按实体墙爆炸。

彩虹拖尾按实际路径保留指定长度，穿门处断开，入口残段短暂淡出，不把入口与出口连成跨图长线。连锁发射统一排队，新生成火箭从下一模拟步开始运动；沿用全场512个投射物上限，超出部分不生成、不补发，并记录未生成数量。

## 可编辑参数

| 参数 | 默认值 |
| --- | --- |
| 百界门重选间隔 | 8秒 |
| 火箭爆炸伤害 | 60 |
| 飞行速度 | 600 |
| 持续转弯速度 | 40°/秒，每枚左右随机 |
| 爆炸半径 | 90 |
| 火箭碰撞半径 | 12 |
| 火箭显示大小 | 48 |
| 彩虹拖尾长度 | 180逻辑单位 |
| 火箭爆炸时限 | 10秒 |

在角色编辑页“技能与状态 → 缇宝 · 百界门与彩虹火箭”调整并保存，试放可预览传送与火箭。随机方向及换门使用战斗随机源，固定配置与种子可重复得到相同事件。

## 多人、时停与结束

多个缇宝共用门，由角色顺序中第一个存活实例提供换门参数；门主死亡后接替，保留当前门与剩余倒计时，下次换门使用接任者参数。每个存活实例发出的火箭使用自己的参数。最后一个实例死亡后门关闭；火箭沿用来源死亡即清理的规则。

时停期间门仍可供活动角色传送，但不发射或补发火箭；换门计时、火箭及寿命冻结。手动暂停冻结整个过程，倍速按战斗时间生效。

胜负确定后停止换门及发射，结算前的4秒移动仍可穿门，但不记录传送或生成火箭。重开、返回选角和关闭编辑页预览清理对应状态。

战报包含换门、角色传送、火箭传送、连锁发射、爆炸和超限未生成事件，记录施术者、触发者、位置及数值；新传送事件另记录入口墙、出口墙和旋转角度，旧记录仍能读取。基础传送通知保持兼容，技能可通过新增的 `on_fighter_portal_rotated(actor, angle)` 同步方向，角度单位为弧度，通知发生在原有位置通知之前。

本机缇宝已保存的转弯值由30同步为40，其余本地角色配置保持原样。其他设备已保存的自定义值不批量迁移，缺少参数时采用新默认40。修改前的工程及本机缇宝配置已备份至 `build/baselines/before-paired-portals-20261027-160641/`。工程仅本地更新，双击 `StartGame.cmd` 查看，不自动打包或发布GitHub。
