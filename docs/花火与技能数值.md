# 花火、毁灭主与技能数值（0.6.0）

## 当前角色与默认规则

当前角色库包含毁灭主、花火，以及0.7.0新增的云璃（见[云璃说明](云璃.md)）。彦卿、姬子、杰帕德、刃不再出现在选角或编辑列表；旧覆盖配置不再重新注册这四个角色，原文件保留以便恢复。旧阵容里的失效角色自动替换成当前角色并使用其默认移动策略。

无特殊说明时，基础血量1000、移动速度160、碰壁反弹，不因普通身体碰撞扣血。新建角色默认没有技能。毁灭主的碰撞重击是明确的例外；花火没有身体碰撞伤害。已有自建角色的主动修改不被统一重置；毁灭主历史默认1100血/158速度迁移成1000/160，其他自定义数值保留。

## 毁灭主

未进入自身碰撞触发范围时蓄力，默认6秒。蓄满时确定敌人的当前位置，只用它确定出手方向；球棒沿该方向飞行固定距离（默认360），再返回本人实时手部位置，不会以敌人位置为去程终点，也不会出程追踪敌人。

去程对每名触碰敌人最多命中一次，返程重新独立判定、每人再最多一次。去程伤害和返程伤害分别配置，默认各60；不再使用基础攻击倍率。球棒离手全程保持图2，接住恢复图1；往返完成后才开始下一次蓄力。

碰撞重击默认伤害120，额外触发距离24（加在双方碰撞半径之和上），击退1100，同目标重击间隔0.65秒。该扩展范围也会重置自身蓄力，持续接触不会逐帧重复伤害。球棒命中击退默认900，仍沿飞行方向造成受击旋转。上述数值均可单独修改。

## 花火

本体使用`280_花火 嘿嘿.png`。红白左轮始终瞄准最近的存活敌人，敌人换到另一侧时角色镜像转身；六膛转盘标出金色实弹和当前枪膛，并随扣扳机转动。队友不作为目标。

每次上膛前六个枪膛均为空，上膛结束后从六膛中等概率选一膛装入唯一实弹，从第一膛逐膛扣扳机。空枪不造成伤害、不生成子弹，枪口弹出白旗和彩带，并播放滑稽短音效；打到实弹膛时发射一枚高速红色子弹，随后立即进入下一轮上膛。每轮最多5次空枪、1次实弹，也可能第一枪就是实弹。

| 数值 | 默认 |
| --- | --- |
| 上膛时间 | 1.2秒 |
| 扣扳机间隔 | 0.35秒 |
| 实弹伤害 | 200 |
| 子弹速度 | 1400 |
| 子弹判定半径 | 6 |
| 子弹击退 | 450，设0可关闭受击击退 |
| 子弹最长飞行时间 | 4秒 |

枪口实时跟随敌人，子弹出手后沿当时方向直线飞行。红色实弹命中最近的碰撞敌人后消失，队友穿透；空枪不会扣血。所有时间使用固定战斗步长，暂停冻结机制，倍速只影响观看速度；声音音高不随倍速变化。

## 在角色里调整

进入“角色编辑 → 属性与技能 → 技能与状态”，选中一个技能，向下滚动到**技能数值**。毁灭主球棒距离、去/回程伤害、飞行速度、命中半径、旋转速度和击退，碰撞额外距离、伤害和间隔，花火的上膛、射击间隔、伤害和速度等均独立保存到当前角色。

蓄力时长及多状态图片仍在原来的阶段设置里。花火上膛时间用专用“上膛时间”数值；蓄力形象可用于上膛阶段。保存后下一局生效，同一角色多次出场也各自持有弹夹、计时和命中记录。

技能参数保存在角色JSON的`skills[].parameters`内，开局按白名单应用到独立技能实例；缺少参数时使用技能默认值，非法范围会被拒绝。后续新技能以`@export`公开数值（支持整数、小数、开关），编辑页自动生成控件；`@export_range`控制范围和步长，中文名称在SkillCatalog.PARAMETER_NAMES中登记。基础节点的内部处理属性不会暴露为技能参数。

本次采用快速验收：当前角色机制、参数编辑保存、移动导航和短时实际窗口效果；历史测试脚本对应旧版本规则，当前入口为`Test.ps1`，阶段扩展用`Test.ps1 -Extended`。
