# 角色编辑与多人对战（0.2.0）

0.4.0 补充：地图默认500×500，主界面新增独立背景音乐开关和音量；重击旋转与击杀退场见 [声音与受击表现](声音与受击表现.md)。

0.7.1 补充：基础属性页移除基础攻击力输入，角色说明支持换行和自动折行。独立技能伤害继续在技能数值中编辑；当前内置默认值见 [本地默认配置](本地默认配置.md)。

## 角色库

主界面点击“角色编辑”。左侧选择角色，可“新建角色”或“复制当前角色”。内置角色修改后保存为覆盖配置，可恢复默认；自建角色可以删除。副本拥有独立标识、属性、技能配置。

- **基础属性**：名称、多行文本域说明、基础血量、速度、默认移动方式。
- **常规形象**：导入 PNG 或从素材库选择，设置显示大小、水平/垂直偏移、碰撞半径和主题色。
- **技能与状态**：从模板添加、移除或排序技能，设置每个技能自己的蓄力和释放形象。
- **保存角色**：写入本地数据，重新启动也会保留；已经开始的战斗使用开局快照，不会被修改影响。

## PNG 与素材库

游戏附带用户提供的 416 张星穹铁道表情图。点“素材库”搜索角色或动作，例如“姬子”“蓄势待发”“看剑”，选中后使用。常规、蓄力和释放图片可以分别选择。

导入外部 PNG 时，游戏验证格式后复制到自己的数据目录。移走原图片不会影响角色。支持透明通道和非正方形图片，按原宽高比显示；单个文件最多 32 MB，宽高最多 8192 像素。显示大小与碰撞半径互相独立。

未配置技能状态图时使用常规形象；常规图也缺失时显示占位图。错误图片会给出提示并保留原设置。

## 技能阶段

| 模板 | 说明 |
| --- | --- |
| 环绕飞剑 | 持续运转，不设置蓄力停顿 |
| 火球、冲刺斩击、近战重击 | 支持真实蓄力、释放形象和蓄力移动开关 |
| 周期护盾、受击反击 | 无蓄力阶段，触发时可显示释放形象 |

蓄力时长范围为 0～10 秒，0 表示立即出手。内置示例默认零蓄力，已为适用角色准备对应状态图。想观看完整蓄力切换，可先把蓄力改为 0.5～1 秒。

0.3.0 新增“毁灭主”，其回旋球棒默认蓄力 6 秒，可编辑为 0～60 秒。球棒接回时才恢复常规形象，不使用固定释放图时长；碰撞重击会中断并重置蓄力。详见 [毁灭主说明](毁灭主.md)。

“释放形象持续时间”只决定图片显示多久，不改变冲刺时长或投射物寿命。每人同时只进行一次主动施法，按技能列表顺序选取可发动技能；被动和持续机制独立运行。蓄力禁止移动时仍可能被击退。目标在蓄力时死亡，会重新寻找敌人；角色死亡和战斗结束会取消阶段。

右侧可以手动切换图片预览，或点击“试放所选技能”观看真实阶段；预览里的测试目标不影响正式战斗。

## 地图与阵容

地图宽和高分别为 480～2400 个游戏单位，默认 664×664。改变尺寸会改变实际空间，角色速度、攻击距离和碰撞尺寸不随之改变；画面自动缩放显示完整矩形地图。

设置 2～8 个参战位置，每个位置独立选择角色与移动策略，可以重复使用同一角色。

- **个人竞技**：每个人独立为战，最后一名存活者获胜。
- **组队对战**：分配到 A～D 队，至少两队有成员；允许 1v7、2v3v3 等人数不等配置。最后一个存活队伍获胜。

队友不受伤害、灼烧或减速，友方身体不拦截投射物；所有存活角色仍有身体碰撞。开局位置按地图和队伍生成，不能容纳角色时禁止开战并说明原因。

## 结算与操作

时限 90 秒。同一步全灭为平局。超时比较每队剩余生命总和÷开局全队生命上限总和；已死亡成员仍计入分母，最高比例并列为平局。个人竞技按个人生命比例比较。没有复活。

Space暂停/继续，R重开，F11全屏/窗口。提供0.5/1/2倍速、音量控制、存活人数、各队人数和各角色血量。所有正式开局都会自动生成与上一局不同的随机种子，界面和战报显示实际值；固定种子仍可在底层测试中用于相同版本与配置下的战况复现。

正常结束的对局（包括平局）自动保存战报和完整事件，中途重开、返回或退出的不保存。桌面顶部、手机配置页与结算页提供记录入口，支持详情、分页、事件筛选和确认删除/清空；详见[对局记录说明](对局记录.md)。

## 数据与升级

存档目录为 `%APPDATA%/StarRingArena/`：`settings.cfg` 保存阵容等设置，`characters/*.json` 保存角色，`characters/images/` 保存外部导入图。内置素材随游戏资源包提供。

更新程序时替换运行文件夹，保留该用户数据目录。旧双人版选角会迁移到稳定角色标识。备份整个数据目录即可保留个人角色与图片。
