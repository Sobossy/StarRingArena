# 记忆·星、迷迷与遐蝶

两名角色已加入选角与角色编辑页，使用用户提供的PNG和已确认的拳击虚影、灰黯之手素材。日常双击工程根目录的 `StartGame.cmd` 运行最新源码；安装包可从GitHub发布页下载。

## 记忆·星与迷迷

记忆·星默认1000生命、160移速、碰壁反弹，常态使用`156_开拓者 记录.png`。迷迷平时跟随头顶，使用`106_迷迷 睡觉.png`；攻击时移动到所选敌人身边，切换`105_迷迷 攻击.png`并播放独立拳击虚影，没有攻击目标后返回头顶。默认出击移动速度800、返回速度650，均可在角色技能数值中调整。迷迷是召唤表现和技能实例，不额外占参战人数，也不增加一个可被攻击的角色；移动表现不改变原有攻击距离、伤害频率或充能规则。

- 近距离每秒拳击13次，每次10伤害。按本地配置同步后的基础攻击距离为50，按双方碰撞圆边缘的间距计算，默认双方半径28时可命中中心距离106以内的敌人。时停期间额外增加10。
- 记忆·星被大运等技能击飞、处于腾空状态时，迷迷停止拳击并返回头顶；落地后按正常拳击间隔恢复，不积攒腾空期间的攻击次数。普通受击击退不属于腾空，不会停止拳击。充能规则保持不变。
- 每次同阵营有效伤害事件充能5%；自己的迷迷每拳仅充能3.5%，不会再额外叠加5%。护盾吸收也算有效伤害，治疗和零伤害不充能。队友的其他迷迷拳击按普通队友伤害计算。
- 满100%自动发动时停，按本地配置同步后的默认时长为3.5秒，切换`083_开拓者 重写.png`。仅发动者及自己的迷迷活动，其他角色（包括队友和其他记忆·星）暂停移动、技能、冷却、状态计时及即时反击；投射物、吐司刷新和灰黯之手缩圈也暂停。
- 时停内不获得充能，结束后从0重新积累。被冻结的敌人仍可被迷迷命中，时停拳击标记“真伤”，目前仍沿用普通伤害的护盾和减伤结算。
- 发动者死亡、对战结束或重开会解除时停。多名角色同时满充能时，按固定事件及角色顺序确定发动者，其余保留已有充能等待恢复。90秒对战时限仍包含时停所经过的时间；手动暂停则冻结全部对战时间。

可调整拳击距离、频率、伤害、两种充能比例、时停时间、距离加成、迷迷显示大小和出击/返回速度。“释放形象”对应记忆·星的时停图。编辑页试放会直接准备满充能，以便查看完整时停和连打。

## 遐蝶与泰坦印记

遐蝶默认1000生命、50移速、碰壁反弹，使用`117_遐蝶 脸红.png`。伤害圈默认半径180，敌人的碰撞圆触及圈即视为入圈。

- 敌人入圈后显示感叹号，遐蝶朝圈内最近敌人追击；圈内无人时恢复选定的默认移动策略。
- 每名敌人分别计时，每满1秒受到25伤害并增加一层印记，最多9层。按本地配置同步后的总减速为`(6 + 当前层数 × 1.5)%`：1层7.5%、2层9%、9层19.5%，不是各层百分比相加。多个遐蝶分别记层，同类减速取最强值，不相乘叠加。
- 每层印记在受影响角色头顶增加一个灰黯之手图案，沿头顶扇形排列；多个遐蝶的印记分行显示。图案与实际层数同步，离圈、来源死亡或重开时随对应印记清除，原有层数文字保留。
- 圈的颜色按圈内最高层数由紫色逐渐变红。目标到9层后，与遐蝶身体碰撞会受到一次100000终结伤害并显示“终结”；不是仅到9层就立即扣除终结伤害。
- 离圈立即清除对应遐蝶的全部印记及减速，重新入圈从0开始。目标腾空无碰撞时也不再处于有效伤害圈。时停期间伤害、叠层、减速和追击暂停，但发动者离开圈仍会立即清除旧印记。
- 遐蝶每次受到有效伤害会向伤害来源反方向额外后退，默认后退幅度18，叠加已有击退并沿用衰减、碰墙反弹等规则；时停冻结期间不会因受伤发生后退。

圈半径、伤害、叠层间隔、最大层数、减速公式、终结伤害和受伤后退幅度均可在角色的技能数值里调整。

## 灰黯之手缩圈

仅存在存活的遐蝶技能角色时启用。四角手形抓住完整棋盘的外框，中心保持不变，每0.5秒减少原始宽、高的1%，最低为原始宽、高的50%；默认累计25秒有效世界时间达到最小范围。地面、背景、完整外框及装饰一起同比缩小，边框厚度和手形同步缩小，角色尺寸保持不变。不是每次对剩余大小乘0.99，也不是面积缩为一半。

多名遐蝶不叠加缩圈速度，采用固定角色顺序中首名存活者的缩圈参数。遐蝶死亡后停止继续收缩，已经缩小的场地不会反弹变大；有其他存活遐蝶则继续。时停和手动暂停期间不缩圈。

画面保持原始地图视野，不因边界收缩自动放大。角色、吐司和腾空落点保持在新的边界内，已有沿线冲刺及绯英冲墙终点同步适配；黄泉永久切面的起点和宽度随棋盘缩进，切口端点与完整外框保持对齐。缩圈间隔、每次缩小比例和最小比例可在角色中修改。
