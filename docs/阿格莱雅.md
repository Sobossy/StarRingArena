# 阿格莱雅 · 金线织途

默认1000生命、160移速、碰壁反弹。常态使用`153_阿格莱雅 设计.png`，沿线冲刺期间使用`152_阿格莱雅 不.png`。两张图片直接使用现有素材库原图。

第一次碰墙留下起始锚点，并牵出跟随角色的金线；此后每次碰墙连接一个新锚点，完成一段金线。墙角同一次碰撞只记一次，重复位置不生成零长度段。连线达到所需段数后，从当前位置沿已记录的路线倒序冲回起始锚点。冲刺结束清除旧线，以终点作为下一轮起始锚点。

所需段数为`向上取整(1 + (当前常态移速 - 本局开局移速) × 0.05)`，至少一段。这里的基准取角色编辑页配置的开局移速，冲刺速度、击退速度和临时减速不计入该差值。默认每轮结束后本局移速增加20，因此默认依次需要1、2、3……段金线，常态移速依次为160、180、200……。移速增加持续到本局结束；重开重置，不写回角色存档，不影响另一个阿格莱雅实例。

- 金线触碰敌人造成50伤害。持续停留在线上不会逐帧受伤；离开再进入可重新触发，同一敌人同一段的触碰间隔默认0.5秒。完成的线段和跟随角色的末端金线都可触发。
- 常态身体碰撞敌人也造成50伤害，同目标间隔默认0.5秒。冲刺期间不叠加这项身体碰撞伤害。
- 每段冲刺伤害为`140 + 本局累计移速提升值`，在该轮开始时锁定。例如第一轮140，第二轮160。每段对同一敌人最多命中一次；同一敌人处于不同线段上时可分别被命中。
- 冲刺速度默认1600。不可阻挡指忽略角色阻挡、击退和减速位移影响，依然正常承受伤害；死亡会终止冲刺。暂停冻结过程，倍速按战斗时间生效，不穿出地图，也不伤队友。

角色编辑页的“技能与状态 → 阿格莱雅 · 金线织途 → 技能数值”可调整初始段数、段数增长系数、每轮加速值、冲刺速度、各项伤害、命中间隔、判定宽度与半径、移速转伤害倍率，以及可选冲刺击退。冲刺形象使用“释放形象”，时长由实际路线决定，固定释放图片时长不参与。点击“试放所选技能”可预览牵线、冲刺和加速。

表现参考用户提供的`QQ20261026-102846.mp4`，金线和拖尾由程序绘制，未从视频提取图像素材或音轨。日常从`StartGame.cmd`运行本地工程查看本次更新，不自动打包或发布。
## 离墙与锚点去重

冲刺结束后先将朝墙方向反射到场内，再施加最多±20°的方向扰动，最终与墙面的夹角默认至少30°。墙角同时满足两面墙；切面墙按角色所属一侧计算内向方向。极窄切面夹角无法容纳设定角度时，采用该区域实际可行的内向角度，避免转向另一面墙。方向扰动使用战斗随机源，固定种子重复运行保持一致。

冲刺结束时立即恢复当前常态移动速度及离墙方向，以终点作为下一轮起点。普通碰墙仅纠正过于贴墙的方向，受击冲量仍沿用原有反弹与衰减。其他角色的碰墙逻辑保持原样。

同帧碰墙仍只记录一次，新线段长度默认至少60。记录接触后，必须先离开对应墙面至少一个角色碰撞半径，才能再次在该墙面记录锚点；墙角同时锁定接触的墙面。未满足条件只反弹，不增加金线段数。缩圈时使用更新后的外墙和切面位置判定离墙距离，不把旧墙面坐标留在状态中。

以上三个参数可在角色技能数值中编辑、保存，旧角色配置缺少时采用60、30°、20°。原有冲刺速度1600、伤害、加速和所需段数公式不变。暂停及倍速仍跟随战斗时间，取消技能、死亡或重开清理离墙锁定状态。本次修复随v0.8.2发布，源码通过 `StartGame.cmd` 查看。
