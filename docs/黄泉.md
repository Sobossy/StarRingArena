# 黄泉：预警斩击与棋盘切面

通过工程根目录的 `StartGame.cmd` 启动最新源码，在选角页选择“黄泉”。默认1000生命、160速度、碰壁反弹，常态使用用户提供的 `262_黄泉 斩断.png`。本次仅更新本地工程，已有Windows运行包、APK和GitHub发行版保持原版本。

## 蓄力与斩击

1. 每轮蓄力7秒。开始时选择最近的存活敌人，预警线中心放在敌人的当前位置；随后以有限速度追踪，默认初始480单位/秒，按`(1−蓄力进度)²`逐渐降到0，因此临近蓄满时会落后于移动的目标。目标死亡后重新寻找敌人，不瞬移到新目标。
2. 每轮随机一个基础角度，在附近小幅随机摆动。默认初始摆幅20°，每0.25秒更新摆动目标；初始旋转限速60°/秒，随蓄力平滑递减到0。7秒时保持当前实际位置和角度，不跳回目标或基准角度。
3. 黄泉的形象从下向上逐渐转为白发、红色眼睛与服饰。原始PNG不修改，通过独立的小型绘制表面实时变色，保持镜像、受击压缩和旋转等效果。
4. 蓄满7秒后，预警线的位置和角度一起锁定，醒目闪烁1.5秒。这段时间敌人可以离开预警线。
5. 锁线结束时贯穿当前地图斩出一击，沿线每名敌人受到一次10000伤害，队友不受伤。判定包括目标碰撞半径和斩击半宽，默认半宽12；沿用普通伤害、护盾及减伤规则，腾空无碰撞角色沿用原有免碰撞规则。
6. 斩击同时从黄泉释放瞬间的可见形象中心向外扩散灰白效果，包含板块偏移、图片位置偏移和腾空上浮。圆心在斩出时固定，后续不跟随角色；窗口缩放与竖屏下也保持对齐。默认0.5秒覆盖整个游戏窗口，包括背景、角色和界面，保留红色斩痕及重点。扩散结束后完整保持1.5秒，合计2秒后恢复色彩，黄泉同时重新开始7秒蓄力。最后一击直接结束对局时，扩散仍完整播放；编辑页试放使用同一全画面效果。

## 永久切面墙

每次斩出的切面成为双面墙，默认半宽7。所有角色，包括黄泉、队友、被击退的角色和冲刺角色，都不能从地面穿过；碰到切面会反弹。阿格莱雅的沿线冲刺遇切面结束，绯英的大运冲撞遇切面视为撞墙结束。没有附加碰墙伤害。

棋盘地面、背景和完整外框一起切开，每侧沿切面法线错开4个逻辑单位，多次切分的累计偏移限制在12单位以内。切开的每块棋盘都有独立的移动相位和速度，在自己的固定位置附近缓慢、小幅移动，不是整张棋盘同步晃动。左右周期约8～13秒、上下周期约10～17秒，总幅度最多1.5单位，不会不断远离；角色、血条、标记和物品随所属板块显示偏移，碰撞和战斗坐标保持稳定。轨迹、金线和切口按板块分段显示。

投射物、球棒、老铁、飞剑和金线等武器效果继续穿过切面。原有腾空无碰撞规则保留，落地时回到合法一侧。重复的同一切面复用已有墙面。已有切面不随施术者死亡、灰白效果结束而消失，重开或返回选角时清除；遐蝶缩圈时完整棋盘、切面起点与宽度、边框和手形一起缩进，角色尺寸不变，视野不自动放大。

## 迷路判负

黄泉每次碰地图外墙或切面墙，都有默认1.5%的概率迷路；同一模拟步的角落或多次位置修正只判定一次。触发时立即判负，不能继续攻击、阻挡或成为目标，同时切换 `261_黄泉 迷茫.png`，保持碰墙前的完整实际速度向量匀速离场，包括当时的击退速度。不额外加速、停顿或旋转；完全离开可视区域后清理。胜负判定不等待动画完成。

胜负确定后所有幸存者继续常态移动和反弹，现实时间4秒后停止并弹出结算。动作跟随倍速，但4秒等待不变；暂停和手机切后台冻结等待。血量、战斗统计和胜负已经锁定，不再攻击、回血、叠状态或缩圈，较慢的迷路离场不会延长结算等待。

## 编辑与验证

“角色编辑 → 技能与状态”可调整蓄力时间及能否移动；“技能数值”可调整锁线时间、伤害、判定半宽、墙面半宽、初始摆幅、摆动间隔、追踪速度、旋转限速、灰白扩散时间、完全灰白保持时间和迷路概率。旧配置的恢复总时长默认1秒升级为新的0.5＋1.5秒；其他自定义总时长换算为保持时间（总时长减扩散时间），保存后使用新字段。其他数值保留。灰白扩散与角色蓄力遵循暂停、倍速及记忆·星时停，固定种子下角度和迷路判定可重复。
